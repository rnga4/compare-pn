# anti-slop audit-002-2026-10-20

Mode: AFTER (audit only). No files modified. Fixes require explicit approval of finding numbers.

Project: compare-pn (FastAPI PN comparison tool)
Scope: UI (app/index.html, app/list.html, app/static/style.css, app/static/app.js, app/static/toast.js, app/static/template.css), backend (app/main.py)

## Findings

### HIGH (Hard Gate)
1. [R-02] Em dash character forbidden: `app/static/app.js` line 54 contains literal em dash `—` in empty state fallback, and line 112 contains `&mdash;` in input hint.
2. [R-03] Mobile control collision: In `list.html`, `#topBtn` is fixed at `bottom: 18px; right: 18px` with `z-index: 40`, directly overlapping `#bAdd` (fixed at `bottom: 16px; right: 16px; z-index: 30`) on screens <= 640px.
3. [R-26] CSV Export logic defect: In `index.html` line 58, `document.querySelectorAll('#body tr')[0].children[i]===td` checks only the first row; for row index > 0, company header resolves to null and exports as empty string for all subsequent rows.
4. [R-26] Search history dropdown unreachable on empty focus: In `index.html` line 100, `if(!$('#q').value.trim()) ... return;` removes `#qhist` when input is empty, preventing users from seeing recent searches when focusing an empty search input.
5. [R-26] Scroll-to-top button broken scroll target: In `list.html` lines 52-53, `#topBtn` listens to `window.scrollY` and calls `window.scrollTo`, but the scrolling container is `.tw.grow`, meaning `#topBtn` never triggers or scrolls the actual list.
6. [R-34] Theme system broken: `app.js` exposes themes (Sakura, Bamboo, Cyberpunk, Mingyu, Ocean, Retrolight) which rely on `template.css` variables (`--background`, `--foreground`), but `style.css` components strictly consume `--bg`, `--tx`, `--bd`, `--ac`, `--mu`, `--hd`, resulting in unstyled/broken theme display.
7. [R-35] Verification & testing: Verification and click-through evidence required across search, filter, dense toggle, export, duplicate modal, and themes.

### MEDIUM (Purpose-Gate)
8. [R-19] Performance & animation jitter: In `style.css` line 210, `* { transition: ... }` applies transitions to all elements; lines 212 & 214 attach `fadeInUp` and `fadeInRow` to every table row and PN badge, causing severe lag and flickering on rapid search queries.
9. [R-10] Glassmorphism without purpose: Inline `backdrop-filter: blur(8px)` on `#qhist` and redundant topbar filters lack purpose documentation.
10. [R-31] Foreign stylesheet conflict (`template.css`): `template.css` (1354 lines) sets `user-select: none` on `body` (preventing users from selecting/copying text manually), injects `body` padding (`padding: 0 24px 10vh 24px`), and overrides layout classes without design rationale.

### LOW (Quality Locks)
11. [R-05] Sticky table header z-index inversion: In `style.css` line 53, `table.data thead th:first-child` has `z-index: 30` which is lower than `thead th` (`z-index: 140`) and `td.nm` (`z-index: 150`), causing the top-left header cell to slide beneath other sticky headers during diagonal scrolling.
12. [R-33] Leftover backup files: `app/static/app.js.bak2` and `app/static/app.js.fixed` are unused artifacts stored in public static directory.

## Recommendation
Approve specific finding numbers to fix. Priority: address HIGH items first (1-7), followed by MEDIUM (8-10) and LOW (11-12).
